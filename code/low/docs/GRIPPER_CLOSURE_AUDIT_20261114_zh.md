## 已核对的数值链路

- 数据右夹爪为 observation.state[30]，训练16维动作中的索引15；左夹爪分别是29、7。训练目标仍为下一时刻 observation，不改用 action。
- take_tube 归一化右夹爪范围为 [0.8465579748, 5.2705583572]；反归一化是 `(a+1)*0.5*(max-min)+min`，没有1.0 rad的闭合下限，0.9 rad可表示。
- 技能门控保留活动右手预测，只保持非工作左手。现有日志中请求右夹爪目标与模型目标逐项完全一致。
- 当前服务器控制桥直接调用 Dex1.command_position。驱动把目标限制在当前反馈±0.18 rad内，再限制到[0,5.4]，Kp=5、Kd=0.05；这不是固定增加0.18 rad。现有身体控制日志没有记录这个限制后的夹爪DDS原始命令，不能声称已直接验证该边界的每条消息。
- 录制数据平台期 action.wbc[30]为0.90000，observation.state[30]约0.90375。两者仅相差约0.00375 rad，不能单独解释当前模型约0.06–0.10 rad的偏开。action仅用于此次只读诊断，没有用于训练或执行。

当前证据定位到部署模型输出已经偏开，不支持仅把原因归结为驱动没有执行更紧的模型目标。因为模型同时接收实机状态，该结果包含闭环状态偏移的影响，并不等同于用录制状态进行的纯离线模型误差。

后续应单独监控夹爪闭合段误差，考虑对该段监督加权；现有权重若需临时验证闭合位置标定，应是显式可开关、只作用于已确定闭合阶段的修正，不能给全部阶段统一减偏置。0.9 rad是这条示范的命令，不是所有试管、载荷和接触位置都能成功夹持的保证。本次未修改任何夹爪命令。
