操作：
1. 第一次 Enter：下半身站立，双臂/夹爪不主动初始化。
2. standing_ready 后第二次 Enter：双臂/夹爪进入指定 observation 初始姿态。
3. 到 ready 后按 b：捕获当前 ego＋双腕图像，Qwen 对这张 ego 自动打框，通常约十秒。
4. 看到“实时目标已就绪”，核对目标框/预览后，第三次 Enter 开始推理。
5. d：原有全身阻尼急停；不等待 Qwen 或 WAM。r：恢复初始化，再 Enter 可重试同一目标。
6. 场景/目标发生变化时，恢复后重新按 b。p 仍可选择初始化动作、轨迹、帧。
键盘焦点需在控制终端；本入口不会自动弹窗抢走急停键焦点。

输入始终是真实 ego＋左右腕相机和实机31维状态。
episode/frame 只用于初始化双臂/夹爪，不会读取数据视频作为推理观测。
只在基本操作开始时提供框；框绑定打框时的未画框原始三路参考图。后续不持续调用Qwen或SAM。
参考PNG、图像SHA256、Qwen响应、预览和marks保存在 runtime/live_operator/<本次ID>/captures。
模型仍为10步、官方默认缓存；当前实时入口为同步chunk执行，沿用已有live client。
保留Dex1-1重力前馈、XR PD、取试管夹爪修正和d/r/p；没有增加运动阈值或控制看门狗。

模型/高层范围：
- take_tube：上面的独立单步流程。
- take_dropper：--model take_dropper --episode 33 --target-description "the dropper in the left reagent bottle"；此默认计划声明左手空、没有任务绑定的右手物体。若右手已持物，请用反映实际状态的 --grounding-plan JSON。
- dispense：--model dispense --episode 133；无需 --target-description。b 仅取实时图像，targets=[]，不请求高层框。
- general：还需 --skill，例如 --skill pick_up_test_tube。模型不会包含试管归架。
- return_tube：--model return_tube --episode 34，使用描述实际右手持管/左手空/目标槽位的 --grounding-plan JSON，或已有 --grounding-session ID。
- return_dropper：现有高层服务无法从真实持滴管状态独立建立单步会话；须使用 --grounding-session ID 接续真实取滴管/加液回执后的高层会话。
- water_bath：低层有权重，但当前高层服务不支持自动标框，本入口明确拒绝，不伪造框或借用其他操作。
--grounding-plan 文件含 plan/layout，全部模型输入必须英文，plan.execution_allowed=false。
--grounding-session 接入真实高层账本，只读取当前步骤并请求框；本入口不提交完成回执、不自动推进实验。
不得将框生成成功当作操作完成。现有高层回执由操作者/上层流程另行提交。

连接：

- WAM：take_tube 默认8849；其他模型默认8850。先正常退出上一控制程序，再切换模型。
